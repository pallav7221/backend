# 🐾 Pet Adoption Management System

Application for managing pet adoptions. This system allows visitors to browse available pets, users to apply for adoption, and admins to manage pets and adoption applications.

## 📋 Features

### Visitor Features
- Browse available pets with beautiful card layout
- Search pets by name or breed
- Filter pets by species, breed, age, gender, and size
- View detailed pet information
- Pagination for easy navigation

### User Features
- User registration and login with JWT authentication
- Apply to adopt available pets
- View personal adoption application status
- Track application history
- User dashboard with profile information

### Admin Features
- Complete pet management (Create, Read, Update, Delete)
- View all adoption applications
- Approve or reject applications with admin notes
- Automatic pet status updates
- Statistics dashboard with overview metrics
- Manage multiple applications efficiently
